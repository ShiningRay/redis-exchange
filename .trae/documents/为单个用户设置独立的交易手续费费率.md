## 实现方案概述

为 Redis Exchange 添加用户级交易手续费费率功能，允许为特定用户设置与市场默认不同的 maker/taker 费率。

### 实现步骤

1. **扩展 Redis 数据模型**
   - 新增 `user_fees:{user_id}` 哈希存储用户级费率配置

2. **修改 Ruby API (lib/redis_exchange.rb)**
   - 添加 `set_user_fees` 方法 - 设置用户费率
   - 添加 `get_user_fees` 方法 - 查询用户费率  
   - 添加 `delete_user_fees` 方法 - 删除用户费率
   - 修改 `execute_order` 方法 - 读取用户费率并传递给 Lua 脚本

3. **修改 Lua 脚本 (redis_scripts/match_order.lua)**
   - 扩展 ARGV 参数接收用户级费率（2 个可选参数）
   - 修改费率选择逻辑：用户费率 > 市场费率
   - 更新脚本头部的 KEYS/ARGV 说明注释

4. **添加测试覆盖**
   - 创建 `spec/redis_exchange/user_fees_spec.rb`
   - 测试费率 CRUD 操作
   - 测试下单时应用用户费率
   - 测试费率优先级和边界情况

5. **更新文档**
   - 在 `docs/architecture.md` 中添加用户费率数据模型说明
   - 更新匹配流程中的费率选择逻辑描述

### 技术要点

- 费率以基点（bps）为单位，范围 0-10000（0-100%）
- 支持 0 费率和负费率（返佣场景）
- 向后兼容：未设置用户费率时使用市场默认费率
- Lua 脚本内原子性保证费率应用的一致性
